# Limitations

- One deep category (power adapters). Other parts go through the generic profile until a
  profile exists for them.
- The app reads what is on the label. A wrong or counterfeit label gives wrong fields; the
  grounding step helps but cannot catch everything.
- Posting to Marketplace stays manual. There is no public listing API for individuals and the
  app does not automate facebook.com.
- Verdicts are only as good as the candidate listing's photos. Blurry screenshots end in
  `INSUFFICIENT_INFO`.
- Human review is required before anything is posted or bought.
