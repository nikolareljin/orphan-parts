# About the author

Nik Reljin is a senior software engineer who likes building software that meets daily life. His
projects cover IoT and home automation, machine learning that runs on local hardware, and making
things: 3D printing and scanning, embedded keyboards and e-paper displays. He also gives retro
and repurposed devices new work, and Orphan Parts Lens comes from that habit: old devices and
loose parts given a second life.

## Other projects

### Hardware and making

- [kinect-forge](https://github.com/nikolareljin/kinect-forge): turns a Kinect v1 into a 3D
  scanner on Ubuntu, from capture and reconstruction to measured, exported meshes.
- [triaina](https://github.com/nikolareljin/triaina): turns an ELEGOO Neptune 4 into an FDM
  printer and drag-knife cutter, controlled by a Raspberry Pi 3.
- [x240-kbd](https://github.com/nikolareljin/x240-kbd): a USB controller for a ThinkPad X240
  keyboard and ClickPad, on a Raspberry Pi Pico with QMK firmware and an OpenSCAD enclosure.
- [ink-mate](https://github.com/nikolareljin/ink-mate): an ESP32-S3 e-paper desk companion with
  voice input, local models and safety-gated tool automation.

### Apps and tools

- [nomisma](https://github.com/nikolareljin/nomisma): coin analysis and cataloging with a digital
  microscope, valuation and marketplace listing.
- [home-monitor](https://github.com/nikolareljin/home-monitor): watches indoor air, weather and
  sensors with a local model and suggests when to open a window or run the AC; syncs with Home
  Assistant.
- [orthodox-calendar](https://github.com/nikolareljin/orthodox-calendar): saints, name days,
  readings, moon phases and ICS feeds for 17 Orthodox and Oriental Orthodox traditions.
- [git-lantern](https://github.com/nikolareljin/git-lantern): a command line that maps local and
  GitHub repositories with branch status, ahead and behind counts and release packaging.

### Security and developer tooling

- [leak-lock](https://github.com/nikolareljin/leak-lock): a VS Code extension that finds secrets
  in git history, checks whether they are live and helps rewrite them out.
- [ci-helpers](https://github.com/nikolareljin/ci-helpers): shared GitHub Actions workflows and
  Bash utilities for tests, builds, deploys and pull request gates.

### Local machine learning workstation

- [nikos](https://github.com/nikolareljin/nikos): turns Ubuntu or Xubuntu LTS into a workstation
  for local models in one Ansible run.
